# ULTrack
Разработка веб-приложения УлТрек

### 1. Клонируйте репозиторий
Каждый делает `git clone <url>` к себе на компьютер — так у всех есть полная история.

### 2. Настройте git (один раз)
`git config --global user.name "Имя"` и `git config --global user.email "email"` — чтобы коммиты были подписаны правильно.

### 3. Работайте в отдельных ветках
Перед новой задачей: `git checkout -b feature-имя`. Не пушить напрямую в `main` — меньше конфликтов.

### 4. Синхронизируйтесь перед работой
Каждый день начинай с `git pull origin main`, чтобы получить свежие изменения друзей.

### 5. Пушьте и создавайте Pull Request
`git push origin feature-имя` → на GitHub нажми **Compare & pull request** → друг проверяет → **Merge**.

### 6. Договоритесь об именах коммитов
Например: `feat: добавил авторизацию`, `fix: исправил баг с кнопкой` — так история читаема.
