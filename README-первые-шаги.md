# Первые шаги с ULTrack

## Что теперь есть

- Главная страница `/` показывает карту с учебными маркерами Ульяновска.
- `GET /api/demo/vehicles/` отдаёт демонстрационный JSON из Django.
- JavaScript загружает ответ сервера и рисует/обновляет маркеры Leaflet.
- Данные **не являются GPS маршруток**. Реальную передачу местоположения ещё нужно спроектировать и реализовать отдельно.
- Подробные объяснения Git, HTTP/HTTPS, JSON, карты и связей файлов находятся в [`Первые шаги Git HTTP JSON и карта.md`](Первые%20шаги%20Git%20HTTP%20JSON%20и%20карта.md).

## Открыть проект в Visual Studio Code

Откройте папку `C:\Учёба\Нейропроект\ULTrack`. Для запуска Django команды выполняются из подпапки `applist`, где лежит `manage.py`.

Эта папка подключена к скопированной истории исходного репозитория: активная ветка — `feature-Maksim`, remote `origin` указывает на GitHub. Локальный коммит не отправляется на сервер автоматически: `push` — отдельное действие. Исходная папка `C:\Учёба\Проект\ULTrack` остаётся отдельной копией и не редактировалась.

## Запуск на Windows

Текущий код исходного проекта указывает на Django 6.1.2. Для него нужен совместимый Python (в этой среде проверена версия 3.11, она слишком старая для Django 6.1). Если у вас установлен Python 3.13:

```powershell
cd "C:\Учёба\Нейропроект\ULTrack\applist"
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r ..\requirements.txt
python manage.py check
python manage.py test
python manage.py runserver
```

Затем откройте `http://127.0.0.1:8000/`. Для просмотра JSON откройте `http://127.0.0.1:8000/api/demo/vehicles/`.

Если на странице отображается старая заглавная страница вместо карты, возможно, в браузере открыт сервер из другой копии проекта или порт `8000` занят старым `runserver`. Остановите старый сервер сочетанием `Ctrl+C` в его терминале, убедитесь, что текущая папка — `C:\Учёба\Нейропроект\ULTrack\applist`, и запустите проект снова. Для проверки можно временно выбрать свободный порт: `python manage.py runserver 8001`, затем открыть `http://127.0.0.1:8001/`.

Если PowerShell запрещает активацию окружения, можно запускать Python напрямую без активации:

```powershell
.\.venv\Scripts\python.exe -m pip install -r ..\requirements.txt
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py test
.\.venv\Scripts\python.exe manage.py runserver
```

Не копируйте `venv` между компьютерами: виртуальное окружение содержит абсолютный путь к конкретной установке Python. Создайте новое локально. Инструкции и причины описаны в учебнике.

## Папки карты

```text
applist/
├── app/urls.py                         # подключение main и auth URL
├── main/urls.py                        # главная страница и карта API
├── main/views.py                       # карта и учебный JSON
├── main/tests.py                       # проверки карты и API
├── main/templates/main/map.html        # HTML-карты
├── main/static/main/
    ├── map.css                         # внешний вид
    └── map.js                          # Leaflet + HTTP GET + маркеры
└── auth/
    ├── urls.py                         # адреса входа и регистрации
    └── views.py                        # страницы входа и регистрации
```

Карта и её API принадлежат приложению `main`. Приложение `auth` отвечает только за авторизацию: `login/` и `register/` внутри префикса `/auth/`.

Leaflet рисует карту и маркеры; тайлы основы сейчас загружаются с OpenStreetMap. Публичный OSM tile-сервер используется в прототипе и не считается гарантированной инфраструктурой для работающего городского сервиса. Для запуска нужно подобрать тайлового поставщика и проверить его условия. Особенно важно: бесплатные условия Яндекс.Карт прямо исключают систему мониторинга транспорта в реальном времени; для такого сценария понадобится коммерческое разрешение/тариф либо другой поставщик.
